# Mount Feast Skardu - Hotel ERP System

Comprehensive **Hotel ERP** desktop system for Mount Feast (Skardu), covering front desk, F&B, inventory, HR, and reporting in one VB.NET solution.

## Overview
Designed for multi-department hotel operations with dedicated modules for guest services, restaurant flows, inventory, laundry, HR, messaging, and management reports.

## Key Modules
- Accounts and financial records
- Human Resource
- Restaurant / F&B
- Inventory and HMS Inventory
- Laundry
- Guest House workflows
- SMS / Email notifications
- Reporting and Crystal Reports assets
- User security / access control

## Tech Stack
- **Language:** Visual Basic .NET (VB.NET)
- **UI:** Windows desktop ERP
- **Database:** Microsoft SQL Server
- **Reporting:** Crystal Reports assets / custom reporting modules
- **Solution:** `Hotel ERP System.sln`

## Getting Started
1. Open `Hotel ERP System.sln` in Visual Studio
2. Review `App.config` / SQL settings for your SQL Server instance
3. Build the solution
4. Run the main ERP project
